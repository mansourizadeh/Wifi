# Wi-Fi Traffic Generator

Two Android phones on the same Wi-Fi/LAN can generate and receive TCP traffic.

GitHub Actions builds a debug APK automatically on push and can also be started manually.

## Use
1. Install the APK on two Android devices.
2. Put one in Receiver mode and note its local IP.
3. Put the other in Sender mode, enter the receiver IP and the same TCP port.
4. Start traffic.

Use only on networks/devices you are authorized to test.
